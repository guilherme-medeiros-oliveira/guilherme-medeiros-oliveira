### 🚀 Projeto em Destaque: NEXUS - HelpDesk System

> Sistema completo de gestão de chamados desenvolvido do zero, focado em experiência do cliente e gestão profissional.

**🔧 O que o sistema faz:**
- ✅ Abertura e acompanhamento de chamados com protocolo `NX-000001`
- 💬 Chat em tempo real entre cliente e suporte (SLA 4h)
- 👥 Painel separado para Cliente e Admin
- 🕐 Horário de Brasília automático + Status dinâmico (Aberto / Em Andamento / Fechado)
- 🔐 Login seguro, permissões e exclusão de chamados

**🌐 Acesse:** `nexus-helpdesk` hospedado na InfinityFree  
**🛠️ Stack:** PHP 8 | MySQL | HTML5 | CSS3 | JavaScript

[🔗 Ver código do NEXUS](https://github.com/guilherme-medeiros-oliveira/helpdesk-nexus) | [🌐 Ver Demo Online](https://guilhermemedeiros.freedev.app/registrar.php)
